01 / CONNECT

Multi-store connections

Give each Shopify store its own company, warehouse, pricelist, sales team, salesperson and connection settings.

02 / IMPORT

Flexible order imports

Import by date range, order ID or checkpoint. Use filtered manual runs or scheduled imports with overlap protection.

03 / CUSTOMERS

Customer resolution

Resolve saved mappings, Shopify IDs, email and phone before creating contacts. Support guests and reusable addresses.

04 / PRODUCTS

Variant-aware matching

Match mapped variants by Shopify variant ID, SKU, attributes and barcode. Keep unmatched products for review.

05 / ACCURACY

Reliable totals

Represent discounts, taxes and shipping, then compare Shopify and Odoo totals against your configured tolerance.

06 / RECOVERY

Recoverable sync

Isolate failures per order, retry queued jobs and inspect actionable logs without duplicating imported records.
