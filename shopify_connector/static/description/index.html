THE DIFFERENCE

One order. One controlled workflow.

Instead of blindly importing disconnected records, the connector follows a dependency-aware sequence. Unresolved mappings can be held for review before a sale order is finalized.

01 / RECEIVE

Fetch order

Read Shopify order details and status.

02 / RESOLVE

Find customer

Match existing partner or create a new one.

03 / ADDRESS

Match addresses

Reuse billing and delivery contacts.

04 / MAP

Validate products

Resolve variants, SKU and barcode.

05 / CREATE

Build sale order

Apply pricing, tax and review rules.

Designed for controlled imports: Each order is processed independently, so an error on one order does not have to interrupt the rest of the batch.

DETAILED FEATURE GUIDE

Built for real-world ERP workflows.

Store & API configuration

  • Separate settings and credentials per store
  • Client ID/secret or access-token authentication
  • GraphQL or REST selection and API version
  • Connection test and Shopify shop metadata
  • Multi-company scoping and access rules

Import controls

  • Manual import by dates or specific order IDs
  • Financial, fulfillment and order status filters
  • Test-order inclusion on request
  • Batch size, page size and overlap settings
  • Scheduled imports and sync-point reset

Customer & product mapping

  • Reusable customer and address mappings
  • Guest checkout handling
  • Catalog fetch and variant matching
  • Unmatched and conflicting variant reporting
  • Review and retry missing-product orders

Accounting & operations

  • Separate shipping and discount order lines
  • Shopify or Odoo tax calculation options
  • COD and prepaid payment-term mapping
  • Optional invoice creation and order confirmation
  • Shopify total comparison and review tolerance

Reliability & recovery

  • Database-backed external ID uniqueness
  • Independent per-order processing
  • Retry queue with manual controls
  • Manual-order duplicate review
  • Scheduled log and completed-job cleanup

Administration

  • Shopify User and Shopify Manager roles
  • Store-specific default sale order values
  • Configurable sale order prefixes
  • Smart buttons for related documents
  • Readable activity and error logs
